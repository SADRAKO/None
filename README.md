# C 语言娘的补习时间

> 校园 × 算法补习向的视觉小说。主角是「我」和 C 语言娘。

- **版本**：0.3.0
- **平台**：Windows（64 位）
- **引擎**：Ren'Py 8.5.3
- **时长**：约 30 分钟

---

## 怎么玩

1. 解压 `C-Lang-Girl-Tutoring-0.3.0-win.zip`
2. 双击里面的 **`C-Lang-Girl-Tutoring.exe`**
3. 完事——**不需要**安装 Ren'Py 或任何其它东西，运行时已经打进包里了

## 操作

| 按键 | 作用 |
| --- | --- |
| 空格 / 回车 / 鼠标左键 | 推进对话 |
| `Ctrl` | 快进 |
| 鼠标右键 | 回退一句 |
| `Esc` | 游戏菜单（存档 / 读档 / 设置 / 退出） |
| `Alt` + `Enter` | 切换全屏 / 窗口 |

随时可以存档。设置里能调文字速度、音量、全屏。答题过程中也能按 `Esc` 存档。

## 故事

第一次程序设计基础小测，我考了 41 分。一个抱着旧书的女孩坐到我对面，
指着屏幕上那行红字说：「第十二行。」

她要帮我过补考，条件是加入她那只有一个人的社团。

**序章 + 五章 + 终章**，每章一道算法题：

| 章 | 地点 | 算法 |
| --- | --- | --- |
| 一 | 校门口便利店 | 贪心（找零） |
| 二 | 社团室 | 冒泡排序 |
| 三 | 社团室 | 二分查找 |
| 四 | 教学楼楼梯 | 递归（爬楼梯） |
| 五 | 校园祭摊位 | 动态规划（凑代币） |

每道题给出 5 种解法，选完会告诉你对不对、复杂度多少、参考思路是什么。
卡住了可以点「问 C」拿提示，**提示不扣分**，一共三级。

### 你的选择会影响结局

每道题的解法都会计入 **C 的信任**：

- **正确解法** — 信任 +8
- **低效解法** — 信任 −20；累计 3 次，补习就到此为止了
- **错误解法** — 直接中断

信任值显示在右上角。结局有两个。

> 提示：低效解法的意思是「结果对但很笨」。如果拿不准，先想想有没有更省的做法。
